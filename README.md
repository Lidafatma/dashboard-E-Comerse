# 📊 Olist E-Commerce Analytics Dashboard

Dashboard analitik interaktif berbasis web yang dibangun menggunakan **React**, **Vite**, **Tailwind CSS**, dan **Recharts** untuk mengeksplorasi dan memvisualisasikan data dari dataset publik *Olist Brazilian E-Commerce*. Proyek ini dirancang untuk menyajikan wawasan mendalam mengenai performa penjualan, perilaku pelanggan, metode pembayaran, hingga sebaran geografis penjual.

🔗 **Live Demo:** [https://lidafatma.github.io/dashboard-E-Comerse/](https://lidafatma.github.io/dashboard-E-Comerse/)

---

## ✨ Fitur Utama

- **Overview (Ringkasan Eksekutif):** Metrik utama performa e-commerce secara keseluruhan (total pesanan, pendapatan, dan pertumbuhan).
- **Products (Analisis Produk):** Eksplorasi kategori produk terlaris dan kontribusinya terhadap pendapatan.
- **Payments (Metode Pembayaran):** Visualisasi preferensi jenis pembayaran yang digunakan oleh pelanggan.
- **Sellers & Seller Cities (Analisis Penjual):** Pemetaan performa dan persebaran kota asal penjual di berbagai wilayah.
- **Reviews (Ulasan Pelanggan):** Analisis kepuasan pelanggan berdasarkan distribusi rating dan ulasan.
- **Customers (Demografi Pelanggan):** Wawasan terkait persebaran dan aktivitas pelanggan.
- **Settings:** Pengaturan tampilan antarmuka dasbor.

---

## 🛠️ Teknologi yang Digunakan

- **Frontend Framework:** React (Vite)
- **Styling:** Tailwind CSS, PostCSS
- **Visualisasi Grafik:** Recharts & Lucide React (Icons)
- **Deployment:** GitHub Pages & GitHub Actions
